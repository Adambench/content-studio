# Content Studio

A one-person content engine: I give it raw material (takes, my voice, products) and press **Make**; Claude makes the
creative choices, local tools do the cutting, grading, sound and rendering, and a checked video or carousel lands in
Review. Runs on a home server (Node 24, SQLite, HyperFrames, FFmpeg), used from a browser, a terminal (`cs`) and an
Android app.

See PLAN.md for the design and CLAUDE.md for how the code is laid out.
